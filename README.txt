AURA Upgraded Clothing Store Demo

Files:
- index.html      Customer storefront
- product.html    Product detail page
- admin.html      Admin dashboard
- app.js          Local data/store logic
- style.css       Shared styling

How to run:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Open admin.html in another tab/window.
4. Add products or publish a sales banner.
5. The storefront syncs from the admin using localStorage/BroadcastChannel.

This is a front-end showcase demo. It does not process real payments or persist data to a server.
